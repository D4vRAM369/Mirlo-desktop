# Conceptos

## Datos estructurados vs. raspado de HTML

Un HTML es una página pensada para que la **lea una persona**: mezcla el post, las respuestas, los menús y los posts recomendados. Un JSON de una API está pensado para que lo **lea un programa**: cada dato tiene su nombre. Si extraes de HTML tienes que adivinar; si lees JSON, preguntas por el campo.
