# Fase 3: base de datos y UI básica

> Informe de task para alguien que sabe algo de programación (por ejemplo Python) pero no domina Rust ni Tauri.

## 1. Resumen para situarse

- **Qué se ha construido:** índice SQLite con búsqueda de texto completo y una UI de tres paneles para guardar, buscar, filtrar, leer y reintentar.
- **Dónde está:** `src-tauri/src/db.rs` (nuevo), `src-tauri/src/main.rs` (comandos), `src/lib/api.ts` (nuevo), `src/App.svelte`.
- **Estado final:** 31 tests en verde, clippy y svelte-check sin avisos, la ventana real abre y crea la BD.

## 2. Flujo

```
Ctrl+V / Enter → api.savePost → save_post (Rust)
   → x_url → sources → vault (disco) → db::upsert (índice)
   ← PostRow → la lista se recarga y el post queda seleccionado
Si falla → db::record_error → aparece en "Con error" con botón Reintentar (R)
```
