# Interfaz bilingüe y preparación de la release

> Informe de task para alguien que sabe algo de programación (por ejemplo Python) pero no domina Rust ni Tauri.

## 1. Resumen para situarse

- **Qué se ha hecho:** la app pasa a llamarse Mirlo, tiene icono y banner propios, interfaz en español e inglés, y la release v0.1.0 quedó preparada y después aplazada para añadir organización y copias de seguridad.
- **Dónde está:** `src-tauri/src/error.rs`, `src/lib/i18n.svelte.ts`, `scripts/check-i18n.mjs`, `CHANGELOG.md`, `docs/ROADMAP.md`.
- **Estado final:** 34 tests, clippy, check y actionlint limpios; CI verde; historial sin datos personales; sin etiquetas.

## 2. Flujo de un error, de Rust a la pantalla

```
x_url::status_id → Err("invalid_link")
   → comando Tauri → frontend: errorParts("invalid_link")
   → t("err.invalid_link") → "No es un enlace válido." / "That is not a valid link."
```
